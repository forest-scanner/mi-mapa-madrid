# 🗺️ Mapa Interactivo de Madrid

Aplicación web interactiva que muestra los principales puntos de interés de Madrid usando Kepler.gl y Streamlit.

## 🚀 Características

- Mapa interactivo centrado en Madrid
- 13 puntos de interés con información detallada
- Tooltips al hacer clic
- Diseño responsive con Streamlit
